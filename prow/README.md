# Open But Unreachable? — Pre-Release Open Window (PROW)

We built PROW, a Python tool that uses 10 Hz NFL tracking data (2021 weeks 1-8, 122 games, 7,221 targeted throws) to measure, for every route runner, how long he has been continuously at least 3 yards from every defender when the ball leaves the quarterback's hand, using only snap-to-release frames (pass outcomes are used only to evaluate it). The data show that being open *at the throw* matters enormously (76% completion vs 47% for a covered target, +29 points, game-bootstrap 95% CI 27-31) but that *how long* the window has been open does not: fresh windows (≤0.5 s) complete 77% vs 75% for windows open >1 s, PROW adds nothing once separation, depth and time-to-throw are controlled (p = 0.62), and the same pattern holds at 2, 3, 4 and 5-yard thresholds. The flip side is the "missed window": on 23.9% of throws (95% CI 22.9-24.9%) the QB targeted a covered receiver while a teammate had been open for at least 1 s, and those throws were completed only 48% of the time. QB coaches can use the Play Lab and the per-QB missed-window chart to pick film on reads, and analysts or recruiters can use PROW to study receivers' separation timing; the tool is descriptive (nearest defender ≠ assigned defender, and an "open" teammate may be outside the progression or unreachable under pressure), not a grade. To run it: `pip install pandas numpy matplotlib statsmodels requests`, then `python download_data.py` and `python prow.py`; figures and `summary.txt` are written to `output/`.
